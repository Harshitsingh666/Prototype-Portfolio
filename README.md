# Prototype Portfolio

A single-page HTML portfolio introducing Harshit Singh's interests, learning areas, and project ideas.

## Preview locally

1. Clone this repository.
2. Open `Portfolio.html` in a modern browser.

No build tools or dependencies are required.

## Sections

- About and learning goals
- Skills grouped by topic
- Project concepts and links
- Education and contact links

## Project file

`Portfolio.html` contains the page markup and links to supporting project assets. Keep linked assets in the repository at the paths used by the HTML file.

## Status

This is an early static portfolio prototype. Some project links point to `Project.html`; that page is not included in the current repository tree.
